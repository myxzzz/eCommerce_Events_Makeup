# 正式 SQL 说明

本目录 SQL 只包含 `SELECT`、CTE 和会话级只读设置，不创建、更新或删除数据库对象。正式 48 小时队列直接从原始事件表重建，不依赖数据库中预先存在的中间表。建议按编号逐个执行。

| 文件 | 输出粒度 | 用途 |
|---|---|---|
| `00_source_profile.sql` | 1 行 | 原始表范围、缺失、异常和完全相同记录检查 |
| `01_cohort_quality.sql` | 1 行 | 48 小时队列完整性、唯一性和标签一致性 |
| `02_kpi_summary_48h.sql` | 1 行 | 正式 A/B/C 主 KPI |
| `03_brand_metrics_48h.sql` | 1 行/品牌 | 品牌覆盖量、结果率、移除/购买比和优先级 |
| `04_funnel_metrics.sql` | 1 行/阶段 | 事件、用户、会话、会话—商品漏斗分层 |
| `05_window_sensitivity.sql` | 1 行/窗口 | 同一 72 小时完整样本的 24/48/72 小时敏感性 |
| `06_cohort_detail_48h.sql` | 1 行/会话—商品 | 从原始事件表只读重建的正式 48 小时明细层 |

所有时间显式按 UTC 解释。正式执行入口是 `scripts/run_formal_validation.py`，它会在只读事务中运行这些查询并导出结果。
