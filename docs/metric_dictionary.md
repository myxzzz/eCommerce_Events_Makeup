# 指标字典

## 1. 核心队列与结果指标

| 指标 | 公式 | 粒度/分母 | 解释边界 |
|---|---|---|---|
| 完整 48 小时加购样本数 | `COUNT(*)` | 完整窗口的 `session × product` | 同一用户可贡献多行 |
| 48 小时购买率 | `A / (A+B+C)` | 全部完整样本 | 主转化指标，不等于用户购买率 |
| 48 小时未明确处置率 | `B / (A+B+C)` | 全部完整样本 | B 可能是持续保留、数据外后续或无操作 |
| 48 小时移除率 | `C / (A+B+C)` | 全部完整样本 | C 必须在窗口内无购买；购买优先 |
| 明确结果购买率 | `A / (A+C)` | 只在 A+C 子样本 | 不能代替整体 48 小时购买率 |
| 移除/购买比 | `C / A` | A>0 的品牌或总体 | 描述性比值；不是“流失概率”或因果风险 |
| 品牌覆盖量 | 品牌的 `A+B+C` 行数 | 完整样本 | 正式版包含 B；旧四象限只用 A+C 会漏掉多数未明确结果 |
| 已知品牌覆盖率 | 品牌非空且不是 `NaN/null/none` 的样本 / 全部完整样本 | 全部完整样本 | 未知品牌不能作为名为 `NaN` 的真实品牌参与排名 |

## 2. 漏斗指标必须分层命名

| 层级 | 浏览 | 加购 | 购买 | 可回答的问题 |
|---|---|---|---|---|
| 事件级 | 事件行数 | 事件行数 | 事件行数 | 行为发生多少次 |
| 用户级 | 去重 `user_id` | 去重 `user_id` | 去重 `user_id` | 当月至少做过该行为的用户覆盖 |
| 会话级 | 去重 `user_session` | 去重 `user_session` | 去重 `user_session` | 至少发生过该行为的会话覆盖 |
| 会话—商品顺序级 | 首次浏览 | 首次加购晚于首次浏览 | 首次购买晚于首次加购 | 同一会话、同一商品的保守顺序漏斗 |

不同层级的漏斗不能混用，也不能把 `session × product` 数量标成“人数”。

## 3. 时间窗口

- 主口径：48 小时。
- 敏感性：24/48/72 小时。
- 敏感性分析固定使用“能完整观察 72 小时”的同一批首次观测加购样本，避免不同窗口因为月末截断而改变分母。
- 事件时间按 UTC 处理。缺少业务所在时区，因此正式结论不使用“上午、晚间、16 点”等本地时间运营建议。
- `user_session` 为缺失、空字符串或 `NaN/null/none` 占位符的记录不进入会话—商品队列；否则会把无关用户错误连接成同一会话。

## 4. 品牌优先级规则

- 最小样本：`clear_outcome_count >= 100` 且 `purchase_count > 0`。
- 高覆盖量：品牌 `brand_cohort_count` 不低于符合条件品牌的中位数。
- 高比值：`remove_to_purchase_ratio >= 1.5`。
- 1.5 是项目启发式筛选线，不是行业标准；正式建议是把它用于排查队列，并在未来用历史基线、置信区间或业务成本校准。

四象限：

- 高覆盖量 + 高比值：优先核查。
- 高覆盖量 + 低比值：规模优势/维护。
- 低覆盖量 + 高比值：监控并补样本。
- 低覆盖量 + 低比值：常规观察。

## 5. 禁止的过度解释

- 品牌排名只能说明差异与排查优先级，不能说明品牌导致移除。
- 数据没有销售额、利润、库存、促销曝光、运费和营销成本，不能计算 GMV 损失、ROI 或库存原因。
- 价格是事件记录价格且币种未知；价格差异可能同时反映商品结构、品类和用户选择。
- 单月数据不能证明季节规律或长期稳定性。
